Collection Hunts — v0.2.0-dev.1i

Known targets: thoridal, onyxian, southwind. Collection Hunts are opt-in.

/wbfyi hunt add thoridal
/wbfyi hunt add onyxian
/wbfyi hunt add southwind
/wbfyi hunt goal thoridal achievement
/wbfyi hunt goal thoridal appearance
/wbfyi hunt goal thoridal item
/wbfyi hunt chars thoridal selected
/wbfyi hunt include thoridal Miraxo
/wbfyi hunt exclude thoridal Miraxo
/wbfyi hunt chars thoridal all
/wbfyi hunt list

The achievement goal for Thori'dal restricts eligibility to Hunter, Warrior, and Rogue.
Item/appearance goals are deliberately marked UNKNOWN, not available, because generic
loot/appearance eligibility is not yet available. Mount presets are available to all
selected discovered characters (subject to raid lockout state).

Selecting 'selected' starts with no characters enabled; use include to opt in.
Characters are identified internally by GUID. To disambiguate two characters with
the same name, enter Name-Realm.

Status: available / done / unknown / excluded / ineligible.
No lockout scans older than 24h are marked unknown. Other characters only update
when you log in and the client supplies saved instance information.

This build does NOT automatically complete a collection hunt when an item drops,
or when the associated FoS is earned. It also does not auto-populate FYI popups.
Configuration remains via slash commands; graphical hunt editor is not included.
