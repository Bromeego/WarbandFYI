WarbandFYI v0.2.0-dev.1k - Collection Hunts editor experiment

- Goal control now opens a dropdown with Achievement, Appearance, and Item.
- Manage Hunts allows shift-clicking an item hyperlink (or entering an item ID) to add a hunt.
- The player MUST manually select a source from three currently supported raid bosses:
  Kil'jaeden / Sunwell Plateau, Onyxia / Onyxia's Lair, Al'Akir / Throne of the Four Winds.
- Selecting a source does not prove that the entered item actually drops there.
- Custom items default to Item goal. Automatic class eligibility for custom targets is
  UNKNOWN, not Available, because no authoritative loot/achievement data has been loaded.
  Their boss lockout snapshot can still be recorded, but an available farming attempt is
  not asserted until eligibility is known. This is a deliberately conservative first step.
- This version does not yet automatically mark newly collected items as complete.
- These features have not been tested in-game.
